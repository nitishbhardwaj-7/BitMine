## 2. Product rules in force (all server-enforced)
- **Daily start:** all mining (paid miners too) stops at the user's local midnight. Start = tap + **2 rewarded videos** (admin → Economics). Owners of an active *purchased* miner start with one tap (perk).
- **Free claims:** 60/day, +5.5 GH/s each until midnight, one video each.
- **Paid miners** (Mini 65 GH/s $1.99, Spark 170 $4.99, Core 360 $9.99, Forge 760 $19.99, Titan 2000 **$79.99**): **auto-renewing monthly subscriptions**, store ids `bitmine_miner_<x>_monthly`. Each paid month = one miner for that period. A subscription can't be bought twice.
- **Super Miner tiers** (extra daily claims), **one-time**: `bitmine_super_basic` $4.99 / 30 days (30 × 5.5 GH/s), `bitmine_super_pro` $49 / 365 days (50 × 10), `bitmine_super_max` $249 / 365 days (50 × 20).
- **Starter Pack** `bitmine_starter_bundle` $3.99 (was $6.98): Mini Miner + Super Miner 30 days; offered 48 h after sign-up until first purchase; popup once a day + card on Home before the streak.
- **Boost video:** doubles running hashpower (max +500 GH/s) for 60 min, 3/day; a video during a boost adds 60 min after it.
- **Streak:** every 7th consecutive started day adds +55 GH/s until midnight.
- **Games** (Home → "Play & earn"): Block Miner, Hash Match. Win → video → +5.5 GH/s until midnight (10 rewards/day). Lose → video → retry (both games locked until watched). Leaving mid-round is not a loss.
- **Reminders:** 3 days / 1 day / at expiry for one-time packs; subscribed miners only if they lapse. In-app only until Firebase is set up.
- **Withdrawals:** min 2,500 sats, email code, manual approval (auto-approve limit 0).
- Rate 48 msat per GH/s per day; mining credited hourly (ledger), Transactions screen shows one total per local day.
- Perks/games/sale banner settings: admin → FAQs & app ("Perks & bonuses", "Sale banner"). Economics are versioned (take effect in the future only).

## 4. How to build, test, deploy (commands that work here)
- **Release build** (from `frontend/`): `VITE_API_URL=https://bitmine.webflowby.online VITE_DEV_SHORTCUTS=false npx vite build && npx cap sync android`, then in `frontend/android`: `JAVA_HOME="C:/Program Files/Android/Android Studio/jbr" BITMINE_VERSION_CODE=<n> BITMINE_VERSION_NAME=1.0.0 ./gradlew.bat assembleRelease bundleRelease -q`. Copy to `D:\BitMine\BitMine-1.0.0-build<n>.apk/.aab`. **Next build number: 36.** Always verify the bundle contains the production URL. (GitHub Actions uses its run number as versionCode, which is lower than local builds: don't upload those to Play.)
- **Backend tests:** `cd backend && npx vitest run` (194 passing; if mongodb-memory-server times out, just re-run). Type-check: `npx tsc --noEmit -p tsconfig.json`.
- **Deploy backend:** from repo root, `tar --exclude=node_modules --exclude=dist --exclude=.env --exclude='.env.*' -czf - backend deploy/Dockerfile deploy/docker-compose.traefik.yml | ssh -i ~/.ssh/bitmine_deploy root@201.18.192.194 'cd /opt/bitmine && tar -xzf - && docker compose -f deploy/docker-compose.traefik.yml --env-file deploy/.env up -d --build'`. One-off scripts: `docker exec bitmine-api node dist/scripts/<name>.js` (e.g. `apply-revenue-features.js`, safe to re-run). Shared server (Dokploy/Traefik): never touch ports 80/443 or other apps.
- **Local dev:** port 4000 is often taken → `cd backend && PORT=4010 npx tsx src/server.ts` and temporarily set `frontend/.env` `VITE_API_URL=http://localhost:4010` (**revert afterwards**). Browser test mode simulates videos/purchases (`DEV_SHORTCUTS`). Local DB is a separate dev database; run `npm run migrate:revenue` there after catalog changes.
- **Emulator:** MuMu, `adb -s 127.0.0.1:16384`; relaunch with `"/d/Program Files/Netease/MuMuPlayer/nx_main/MuMuManager.exe" control -v 0 launch`. It shuts down often; screen 1600×900 landscape. Signed in as the owner's test account.
- **Editing gotchas:** files are CRLF → use the exact-match patcher pattern (a small node script) instead of sed for multi-line edits; never put template literals with `${}` inside `node -e "…"` in bash; parallel shell calls share a cwd.
